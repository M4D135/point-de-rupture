Le module PDR.immeubles (Jeu/src/sim/immeubles.js, chargé avant monde.js) simule les immeubles en feu en mètres et en secondes : `creer(liste)` rend I (I.n immeubles ; par indice k : I.id, I.x, I.z, I.etat (0 intact, 1 en feu, 2 éteint, 3 calciné), I.intensite, I.origine (camp qui l'a allumé, -1 sinon) ; I.enFeu) ; `chauffer(I, x, z, force, dt, camp, evts)` ; `cocktail(I, x, z, camp, tirage, evts)` (l'immeuble prend si `tirage % 3 === 0`) ; `allumer(I, k, camp, evts)` ; `avancer(I, dt, evts)` ; `arroser(I, x, z, rayon, debit, dt, evts)` ; `pres(I, x, z)` et `proche(I, x, z, rayon)` (indice d'un immeuble en feu, ou -1) ; `distFacade(I, k, x, z)` ; `exporter(I, sortie)` ; `empreinte(I)`. Ses évènements sont des objets poussés dans `evts` : `{ type: 38, a: id, b: camp }` (il prend feu) et `{ type: 39, a: id, b }` (b = 0 : éteint à l'eau ; b = 1 : calciné). Les id de ville.sites.immeubles sont leurs indices : k = id. Dans monde.js les positions sont en millimètres (entiers) : divise par 1000 pour le module, multiplie par 1000 (Math.round) pour revenir.
Les Pompiers (type 13) et le Camion de pompiers (14) de la Préfecture ont la capacité `lance: { portee, debit }` (regles.js ; mètres ; débit 1 pour un pompier, 4,5 pour le camion). L'ordre `CMD.ETEINDRE` (`{ ids, x, z }`, protocole.js) les envoie arroser un point. Dans Jeu/src/sim/monde.js :
1. Table T : `lance: new Uint8Array(NT), lancePortee: new Int32Array(NT), lanceDebit: new Int32Array(NT),` (portée en mm, débit en millièmes) ; remplissage, à côté de `T.molotov[k] = …` : `T.lance[k] = c.lance ? 1 : 0; T.lancePortee[k] = c.lance ? Math.round(c.lance.portee * 1000) : 0; T.lanceDebit[k] = c.lance ? Math.round(c.lance.debit * 1000) : 0;`.
2. Ordres : `case CMD.CAPACITE: case CMD.MOLOTOV: case CMD.ETEINDRE: {` ; `cap` vaut `'lance'` pour ETEINDRE (`c.t === CMD.MOLOTOV ? 'molotov' : c.t === CMD.ETEINDRE ? 'lance' : c.capacite`) et sa table est `T.lance`. Le reste du cas sert tel quel : l'unité part vers le point en ordre O.CAPACITE. Complète le commentaire du cas.
3. Exécution de l'ordre O.CAPACITE dans la boucle des unités : une unité à lance (`T.lance[t]`) a la sorte 0 (le jet) et sa propre portée : `portee = … : T.lance[t] ? T.lancePortee[t] : JET_PORTEE`. Elle est aussi à portée quand le point visé est sur un immeuble en feu dont la façade est à moins de sa portée : `const ki = T.lance[t] && IMM.enFeu > 0 ? PDR.immeubles.pres(IMM, usx[i] / 1000, usz[i] / 1000) : -1;` et la condition devient `d2 <= portee * portee || (ki >= 0 && PDR.immeubles.distFacade(IMM, ki, x / 1000, z / 1000) * 1000 <= portee)`. Elle lance alors son jet avec `lancerJet`, comme le Canon à eau (la fiche suivante fait que ce jet arrose sans frapper personne).
