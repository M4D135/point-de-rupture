Contrat de la 0.3 (Jeu/PLAN.md, décision D9 : les immeubles prennent feu si les pompiers ne viennent pas éteindre) : `ville.sites.immeubles` est la liste des immeubles qui peuvent brûler, que la simulation donne au module PDR.immeubles. Chaque entrée : `{ id, x, z, rayon, h, boites: [{ x, z, lx, lz, lacet }], pieces }`, en mètres : id = son indice dans la liste ; (x, z) son centre ; rayon : le cercle qui contient toutes ses boîtes ; h : la hauteur de son toit ; boites : son emprise (lx, lz : dimensions complètes ; lacet : rotation autour de la verticale, 0 : lx le long de x, π/2 : lx le long de z) ; pieces : `[premier, fin)`, les indices de ses pièces dans `objets` (tableau vide si on ne les connaît pas).
Dans Jeu/src/ville.js (la ville imaginaire) :
1. Renomme la fonction `immeuble` en `immeubleSeul` (seule sa première ligne change ; son commentaire reste au-dessus d'elle).
2. Juste avant ce commentaire (`/** Un immeuble sur l'emprise donnée ; rend la hauteur du toit. */`), ajoute un commentaire d'une ligne, `const immeubles = [];` et une nouvelle `const immeuble = (x0, z0, x1, z1, h, couleur, details = true) => { … };` qui retient `const debut = objets.length;`, appelle `immeubleSeul(x0, z0, x1, z1, h, couleur, details)` et garde son résultat `toit` ; si `details` est vrai (les autres sont des bâtiments à part, qui ne brûlent pas), elle ajoute à `immeubles` : `{ id: immeubles.length, x: (x0 + x1) / 2, z: (z0 + z1) / 2, rayon: Math.hypot(x1 - x0, z1 - z0) / 2, h: toit, boites: [{ x: (x0 + x1) / 2, z: (z0 + z1) / 2, lx: x1 - x0, lz: z1 - z0, lacet: 0 }], pieces: [debut, objets.length] }` ; elle rend `toit`. Elle ne tire aucun nombre au hasard : la ville reste la même pour une même graine. (immeubleSeul est appelée plus tard, une fois définie.)
3. `const sites = { qg, lieux, gisements, cassables, immeubles };`.
Rien d'autre ne change.
