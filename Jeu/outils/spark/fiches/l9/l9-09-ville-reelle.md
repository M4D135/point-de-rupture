Contrat de la 0.3 (Jeu/PLAN.md, décision D9 : les immeubles prennent feu si les pompiers ne viennent pas éteindre) : `ville.sites.immeubles` est la liste des immeubles qui peuvent brûler, que la simulation donne au module PDR.immeubles. Chaque entrée : `{ id, x, z, rayon, h, boites: [{ x, z, lx, lz, lacet }], pieces }`, en mètres : id = son indice dans la liste ; (x, z) son centre ; rayon : le cercle qui contient toutes ses boîtes ; h : la hauteur de son toit ; boites : son emprise (lx, lz : dimensions complètes ; lacet : rotation autour de la verticale, 0 : lx le long de x, π/2 : lx le long de z) ; pieces : `[premier, fin)`, les indices de ses pièces dans `objets` (tableau vide si on ne les connaît pas).
Dans Jeu/src/ville-reelle.js (Marseille), les bâtiments sont dans le tableau `bats` (objets `bat`, voir l'extrait) ; chaque boîte `bx` de `bat.boites` a un centre (bx.x, bx.z), un axe unitaire (bx.ux, bx.uz) le long duquel elle s'étend de ± bx.a, et de ± bx.b en travers.
1. Juste après la ligne `chrono('batiments');`, construis `const immeubles = [];` : pour chaque `bat` de `bats` tel que `bat.detail && !(bat.monument >= 0) && !bat.hote && bat.A >= 30` (ni monuments ni petits kiosques), avec `boites` = pour chaque bx : `{ x: bx.x, z: bx.z, lx: 2 * bx.a, lz: 2 * bx.b, lacet: Math.atan2(bx.uz, bx.ux) }` ; (x, z) = la moyenne des centres des boîtes pondérée par leur aire (bx.a × bx.b) ; rayon = le plus grand `Math.hypot(bx.x - x, bx.z - z) + Math.hypot(bx.a, bx.b)` ; pousse `{ id: immeubles.length, x, z, rayon, h: bat.h, boites, pieces: [] }` et note `bat.immeuble = id` (les autres bâtiments : `bat.immeuble = -1`), pour le dessin à venir. N'utilise pas lacetDe : sa convention est celle du dessin, pas celle-ci.
2. Dans l'objet `ville`, `sites: { qg, lieux, gisements, cassables, immeubles }`.
Rien d'autre ne change ; aucun tirage au hasard de plus.
