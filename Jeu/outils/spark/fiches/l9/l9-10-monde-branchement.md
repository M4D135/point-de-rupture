Le module PDR.immeubles (Jeu/src/sim/immeubles.js, chargé avant monde.js) simule les immeubles en feu en mètres et en secondes : `creer(liste)` rend I (I.n immeubles ; par indice k : I.id, I.x, I.z, I.etat (0 intact, 1 en feu, 2 éteint, 3 calciné), I.intensite, I.origine (camp qui l'a allumé, -1 sinon) ; I.enFeu) ; `chauffer(I, x, z, force, dt, camp, evts)` ; `cocktail(I, x, z, camp, tirage, evts)` (l'immeuble prend si `tirage % 3 === 0`) ; `allumer(I, k, camp, evts)` ; `avancer(I, dt, evts)` ; `arroser(I, x, z, rayon, debit, dt, evts)` ; `pres(I, x, z)` et `proche(I, x, z, rayon)` (indice d'un immeuble en feu, ou -1) ; `distFacade(I, k, x, z)` ; `exporter(I, sortie)` ; `empreinte(I)`. Ses évènements sont des objets poussés dans `evts` : `{ type: 38, a: id, b: camp }` (il prend feu) et `{ type: 39, a: id, b }` (b = 0 : éteint à l'eau ; b = 1 : calciné). Les id de ville.sites.immeubles sont leurs indices : k = id. Dans monde.js les positions sont en millimètres (entiers) : divise par 1000 pour le module, multiplie par 1000 (Math.round) pour revenir.
Dans Jeu/src/sim/monde.js :
1. Après `const sites = ville.sites;` : une ligne de commentaire (0.3, PLAN D9 : les immeubles qui brûlent), puis `const IMM = PDR.immeubles.creer(sites.immeubles || []), evIm = [];` et `let versionImm = 0, immEnvoyes = 0;` (la fiche suivante s'en sert pour l'envoi à la page).
2. Le bilan de chaque camp gagne `immeublesBrules: 0, immeublesSauves: 0`.
3. `avancerFeux` : après la boucle des foyers (avant `if (grilleFeux) majGrilleFeux();`), si `IMM.n > 0`, chaque foyer actif q chauffe les façades proches : `PDR.immeubles.chauffer(IMM, fX[q] / 1000, fZ[q] / 1000, Math.min(1, (fAge[q] + 6) / (fDelai[q] + 12), fReste[q] / (3 * IT_S)), 1 / IT_S, fCamp[q], evIm);` (l'intensité est celle que reçoit la page).
4. `molotovTombe(x, z, f, tireur)` : en tête, `if (IMM.n > 0) PDR.immeubles.cocktail(IMM, x / 1000, z / 1000, f, (Math.imul(it + 1, 0x9E3779B1) ^ Math.imul(x | 0, 0x85EBCA6B) ^ (z | 0)) >>> 0, evIm);` (tirage déterministe sans toucher au générateur de la partie).
5. Deux fonctions près de molotovTombe : `function allumerImmeuble(k, camp)` (pour l'IA et les essais : `if (k >= 0 && k < IMM.n) PDR.immeubles.allumer(IMM, k, camp, evIm);`) et `function viderImmeubles()` : pour chaque e de evIm, `k = e.a`, `x = Math.round(IMM.x[k] * 1000)`, `z = Math.round(IMM.z[k] * 1000)` ; type 38 : `evenement(EV.IMMEUBLE_FEU, x, z, e.b, e.a, 0)` ; type 39 et `e.b === 0` : `evenement(EV.IMMEUBLE_ETEINT, x, z, PREF, e.a, 1)` et `bilan[PREF].immeublesSauves++` ; type 39 et `e.b === 1` : `evenement(EV.IMMEUBLE_ETEINT, x, z, -1, e.a, 0)` et, si `IMM.origine[k] >= 0`, `bilan[IMM.origine[k]].immeublesBrules++` ; puis `versionImm++` et `evIm.length = 0`.
6. `iterer` : juste après `avancerNuages();`, `if (IMM.n > 0 && it % IT_S === 11) PDR.immeubles.avancer(IMM, 1, evIm);` (une fois par seconde) ; juste avant `it++;`, `if (evIm.length) viderImmeubles();`.
